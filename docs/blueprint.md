# **App Name**: ScamDetective

## Core Features:

- Dashboard Overview: Display a summary of the user's scam detection activity, including recent scans, potential threats identified, and overall risk score.
- Quick Scan: Allow users to quickly scan a phone number, email address, or website URL for known scam indicators.
- Scan History: Maintain a record of all previous scans, allowing users to review past results and track potential scam trends.
- Suspicious content identifier: Integrate an AI powered tool to find the likelihood that text-based content might be used in scams and assign it a score, and also output the rationale for assigning a specific score.
- Web Extension: Offer a browser extension that automatically scans websites visited by the user for scam indicators.
- Reporting: Enable users to report suspected scams and fraudulent activity to a central database for analysis.
- Settings Management: Provide a user-friendly interface for managing app settings, preferences, and subscription details.

## Style Guidelines:

- Primary color: Forest Green (#006434) to inspire trust and security.
- Background color: Light beige (#F5F5DC) to provide a soft, neutral backdrop.
- Body and headline font: 'PT Sans', a humanist sans-serif, providing a balance of modernity and warmth for readability and approachability
- Use clear and concise icons to represent different features and actions within the app.
- Employ a clean and intuitive layout that prioritizes ease of navigation and scannability.
- Incorporate subtle animations and transitions to enhance the user experience and provide visual feedback.
